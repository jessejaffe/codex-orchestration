# On-demand usage comparison

Normal routing never reads this file, invokes `usage-receipt.py`, or runs a receipt
hook. That keeps usage discovery, transcript traversal, pricing refreshes, and any
extra model continuation entirely off the task path.

For diagnosis or an explicit user request, `usage-receipt.py recover` can reconstruct
a completed root turn and native descendants. Its same-token model-family comparison
does not establish hidden reasoning-credit differences between Sol effort levels.
Never interpret equal public rates as proof that lower Sol effort saved no credits.

Longitudinal account measurement remains available through
`effectiveness-tracker.py`. Both tools are offline diagnostics; neither is imported by
the prompt hook.
