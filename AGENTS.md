# Repository guidance

## Public distribution

This repository is the stripped-down public distribution of Codex Orchestration. Keep tracked
content limited to the repository guidance, public documentation and license, marketplace
descriptor, and installable `plugins/codex-orchestration` package. Do not add synchronized chat or
project material, user-specific runtime state, local caches, credentials, or unrelated development
artifacts.

## Publication

GitHub publication for this repository is always authorized. Completed repository changes may be
committed and pushed to the configured `origin` remote,
`git@github.com:jessejaffe/codex-orchestration.git`, including its default `main` branch. Before a
push, establish a fresh remote baseline and preserve concurrent work. This authorization is limited
to this repository's GitHub publication; it does not authorize deployment to another destination or
changes to another project.
